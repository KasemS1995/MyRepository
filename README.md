# Forever with BTS - Project Summary 💜

## Overview
เว็บไซต์อวยพรและให้กำลังใจศิลปินวง **BTS** ตกแต่งด้วย Theme สีม่วง (Borahae) เพื่อแสดงความรักจาก ARMY

## Features
- **Hero Section**: ข้อความต้อนรับและรายชื่อสมาชิกทั้ง 7 คน
- **Wishes Cards**: การ์ดคำอวยพรความหมายดีๆ
- **Wishes Form**: ฟอร์มสำหรับให้ผู้เยี่ยมชมร่วมส่งคำอวยพร (เก็บข้อมูลใน LocalStorage ทำให้กลับมาดูข้อความเดิมได้)

## Tech Stack
- **HTML5**: โครงสร้างหลักของเว็บไซต์
- **Tailwind CSS** (via CDN): ใช้สำหรับตกแต่งดีไซน์ให้สวยงามและ Responsive
- **JavaScript**: ใช้จัดการ Logic การบันทึกและแสดงผลคำอวยพร
- **Font**: Google Fonts (Prompt)

## How to Run
เพียงแค่เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ ก็สามารถใช้งานได้ทันที!
